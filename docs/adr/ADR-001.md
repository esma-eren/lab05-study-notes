# ADR-001: AI-Assisted Development and Testing

**Date:** 2026-11-11
**Author:** Esma Eren
**Milestone:** Lab 5 / P3
**Tool and model used:** ChatGPT (GPT-6)

## Context

I was completing the Study Notes Flutter application.
I needed to verify Firebase Authentication error handling and
write my own meaningful tests.
I wanted to keep the tests simple and easy to understand.

## Prompt

"Help me write meaningful tests for AuthRepository.
Explain which file to modify and provide the complete code.
Make sure the tests verify Firebase error messages."

## Result

AI helped me write additional tests in test/own_test.dart.
The tests verify weak-password, network-request-failed,
and invalid-email error messages using AuthRepository.messageFor().

## Rejected suggestion(s) — at least one

An earlier suggestion used mocktail and mocked FirebaseAuth
to test sign-in and sign-up operations.
I did not retain this approach because it introduced
unnecessary complexity for my current testing requirements.
I chose simpler tests for error message mapping instead.

## Verification

I ran flutter test in the terminal.
All 18 tests passed successfully.
I also reviewed the expected messages in each test.

## What I learned

I learned how to test Firebase error handling without
connecting to a real Firebase project.
I also learned to review and verify AI-generated code
before using it in my project.
